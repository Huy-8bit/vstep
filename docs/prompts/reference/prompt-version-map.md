[Kết quả kiểm tra cục bộ](documentation-audit.json) ghi số lượng tài liệu/schema, liên kết, placeholders và hash nguồn đã đối chiếu. Đây là kiểm tra cấu trúc và đồng bộ tài liệu; không phải đánh giá chất lượng câu trả lời của chatbot hoặc audio thật.

## Known differences and coverage

- Current Writing core is 4.1.0, source analysis/calibration strings 3.0.0, escalation 1.5.0; old full `GradingOutput` is not the current provider core. Standalone Writing task level remains unavailable, despite illustrative requests for a level beside every task.
- Speaking corrections are included in text grading 2.1.0; Writing optional feedback is lazy 1.0.0. Audio 2.0.0 owns pronunciation/fluency. Aggregate rounding and level rounding differ and are documented.
- Vocabulary Coach 1.0.0 returns 5–8 topic items plus supported correction/history items (max 16); quick/all-in-one human mode may select 5–10 for convenience. Reading coach returns 5 actual passage items or 1 selected item.
- Analysis/taxonomy/plans are deterministic Python/SQL; lesson/exercise/weekly prose are AI-backed. No prompt is invented as if a deterministic function made API calls.
- Import and quality-review prompt strings lack dedicated prompt-version constants. Quality validators/reference are 3.0.0; import is tracked by source hash/commit. Transcription/TTS are provider operations without a text-grading prompt version.
- Independent generation-quality checks, import/OCR, transcription, TTS/reference audio, scripted pronunciation practice, optional Writing feedback, exercise feedback and vocabulary usage are covered in addition to the requested main list.
- No Listening feature exists here. Persistence, ownership, bank selection/deduplication, caching, scheduling and cost metering are application operations; no chatbot prompt can replace them automatically.
- Chatbot-specific microphone/upload/JSON behavior was not validated by paid API calls in this documentation task. Manual output must be reviewed; an examiner-rated holdout is still a separate quality step.
